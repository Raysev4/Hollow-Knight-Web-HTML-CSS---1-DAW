# Hollow Knight - Web Project

## Descripción

Desarrollo de una página web inspirada en el videojuego Hollow Knight, realizada como ejercicio práctico durante el primer curso del ciclo formativo de Desarrollo de Aplicaciones Web (DAW).

El proyecto tiene como objetivo poner en práctica los conocimientos adquiridos sobre desarrollo web, estructura de documentos y diseño de interfaces.

## Tecnologías utilizadas

- HTML5
- CSS3

## Características

- Diseño web inspirado en el universo de Hollow Knight.
- Estructuración de contenidos mediante HTML.
- Estilización y maquetación mediante CSS.
